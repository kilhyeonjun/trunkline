# Trunkline v0.1.0

Trunkline's first public alpha release provides a local-first CLI and native
macOS menu bar app for named Codex authentication snapshots, manual switching,
local usage monitoring, and automatic fallback.

## Highlights

- Installable `trunkline` Python CLI
- Atomic local credential snapshot switching
- Pin, automatic fallback, lock, status, and usage commands
- Native macOS menu bar status and allowlisted actions
- Conservative installer and uninstaller that preserve user data by default

## Safety contract

Trunkline treats credential files as opaque bytes, does not store token values
in its metadata, and does not add a token-refresh path. Back up existing
credentials and test with non-critical accounts before initialization.

## Install

Requires Python 3.11 or later:

```bash
pipx install https://github.com/kilhyeonjun/trunkline/releases/download/v0.1.0/trunkline-0.1.0-py3-none-any.whl
trunkline --help
```

The attached `trunkline-0.1.0-py3-none-any.whl.sha256` file contains the
SHA-256 checksum for the wheel.

The optional menu bar app requires macOS 14 or later and Swift 6/Xcode to build
from source. Run `bash scripts/install.sh` from a source checkout.

## Known limitations

- This is alpha software.
- Codex is the only provider with account switching.
- The app is ad-hoc signed, is not notarized, and is not attached to this
  release.
- There is no PyPI or Homebrew distribution and no automatic updater.
