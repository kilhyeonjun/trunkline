# Trunkline v0.1.1

This local release candidate adds model-scoped account-health handling for
Codex while keeping account switching local-first.

## Highlights

- Exact Codex entitlement failures are scoped to provider, account label, and
  model before `auto` considers a fallback. Lock mode records health but never
  switches an account.
- `trunkline health` shows only persisted, redacted health state. The explicit
  `trunkline health --probe --model MODEL` request can consume paid usage, runs
  once in a read-only ephemeral Codex session, and never stores or prints raw
  output, tokens, emails, or account IDs.
- The daemon never runs probes or adds background entitlement inference.

## Install

Requires Python 3.11 or later:

```bash
pipx install https://github.com/kilhyeonjun/trunkline/releases/download/v0.1.1/trunkline-0.1.1-py3-none-any.whl
trunkline --help
```

Verify `trunkline-0.1.1-py3-none-any.whl` against its published SHA-256 file
before installation.

## Update and rollback

Before updating, back up `~/.codex` and `~/.trunkline`. To roll back, install
the previously verified v0.1.0 wheel with `pipx install --force`; this does not
delete Trunkline state or snapshots. Confirm `trunkline health` before using
`auto` again.

## Known limitations

- This is alpha software. Codex is the only account-switching provider.
- The menu bar app requires macOS 14 or later and Swift 6/Xcode to build.
- The app is ad-hoc signed and not notarized; there is no PyPI, Homebrew, or
  automatic-update channel.
